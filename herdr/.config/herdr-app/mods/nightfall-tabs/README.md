# nightfall-tabs

Part of the Nightfall layout. See [layouts/README.md](../../layouts/README.md) for what it
draws, the block it lives in, and how to install the whole layout.

## Install on its own

```sh
cp -R mods/nightfall-tabs ~/.config/herdr-app/mods/
herdr-app check ~/.config/herdr-app/mods/nightfall-tabs
```

It uses icons from `mods/nightfall-chrome/`, so install that mod too.

`run-scripts.js` is a copy of `mods/run-scripts/scripts.js`: keep the two the same. The
panel buttons for CI and Slack use those mods' icons.
