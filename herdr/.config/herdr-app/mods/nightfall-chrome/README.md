# nightfall-chrome

Part of the Nightfall layout. See [layouts/README.md](../../layouts/README.md) for what it
draws, the block it lives in, and how to install the whole layout.

## Install on its own

```sh
cp -R mods/nightfall-chrome ~/.config/herdr-app/mods/
herdr-app check ~/.config/herdr-app/mods/nightfall-chrome
```

It holds the icons the other Nightfall mods use and the Geist Mono Nightfall font
(`fonts/`, SIL Open Font License), which Herdr loads at start.
