# nightfall-changes

Part of the Nightfall layout. See [layouts/README.md](../../layouts/README.md) for what it
draws, the block it lives in, and how to install the whole layout.

## Install on its own

```sh
cp -R mods/nightfall-changes ~/.config/herdr-app/mods/
herdr-app check ~/.config/herdr-app/mods/nightfall-changes
```

It needs no other mod.
